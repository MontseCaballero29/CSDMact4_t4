# CSDMact4_t4

Estructura inicial de la Actividad 4 del Tema 4.

## Proyecto

API REST pura con Spring Boot, Spring Security, JWT, JPA, MySQL y Bruno.

## Relación principal

- Una `Categoria` tiene muchos `Producto`.
- Un `Producto` pertenece a una `Categoria`.

## Estado actual

Solo contiene la estructura inicial del proyecto. Las entidades, DTOs, repositorios, servicios, controladores, seguridad JWT y colección de Bruno se implementarán paso a paso.
